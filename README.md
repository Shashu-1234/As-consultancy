# AS Career Consultancy Website V2

This is the redesigned multi-page version of the AS Career Consultancy website.

## What's improved
- Multi-page structure instead of one long single page
- More modern color palette
- Better visual hierarchy
- Cleaner professional design
- Dedicated About, Services, Opportunities and Contact pages
- WhatsApp enquiry form
- Responsive layout for desktop and mobile
- Ready for static deployment on Vercel / GitHub Pages / Netlify

## Pages
- `index.html`
- `about.html`
- `services.html`
- `opportunities.html`
- `contact.html`

## Important
Before publishing, AS Career Consultancy should verify:
- exact service charges
- registration amount
- refund/cancellation terms
- live opportunity claims
- office address and contact details

This repository contains a self-contained static multi-page build ready for Vercel.
